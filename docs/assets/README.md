# README artwork

`loboot-hero.png` was created for this project on 2026-10-13 with OpenAI image generation, using the project owner's supplied [locron](https://github.com/WhiteKiwi/locron) banner as a visual reference. At the owner's request, it preserves the same Roki mascot: a round cream robot with a dark face, yellow eyes, and an antenna.

The warm ivory, charcoal, and amber illustration shows Roki launching application windows from a laptop at login. The login/sunrise motif and separate application windows express the user-service workflow. macOS and Linux are the supported platforms; the scene does not represent machine-wide or pre-login boot services.

The image is decorative; the README text and examples are the source of truth for supported behavior. The project is licensed under MIT OR Apache-2.0; see the repository license files. This note records image provenance rather than changing those terms.

## README design references

- [locron](https://github.com/WhiteKiwi/locron): centered illustrated banner and compact product introduction.
- [uv](https://github.com/astral-sh/uv): scannable benefits and concrete command examples.
- [fd](https://github.com/sharkdp/fd): compact navigation and explicit scope.
- [zoxide](https://github.com/ajeetdsouza/zoxide): immediate usage examples and separate installation guidance.
- [Starship](https://github.com/starship/starship): clear identity, prerequisites, and platform disclosure.

These informed the information hierarchy, not claims of feature or platform parity.
